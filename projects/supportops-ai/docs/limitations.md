# Limitações

- Dados sintéticos, sem impacto de negócio medido.
- Busca lexical não entende sinônimos; coincidência de termos não garante relevância.
- IDs válidos não comprovam fidelidade semântica das respostas.
- Instruções ao modelo não constituem proteção comprovada contra prompt injection.
- Inferência real e avaliação quantitativa pendentes.
- API local sem autenticação, persistência ou integração externa.
- Dependências diretas fixadas; lock transitivo e Docker pendentes.
- Hash identifica versão; histórico depende do Git.
