# Dados

Usei políticas e pedidos sintéticos gerados com apoio de IA para esta demonstração. Disponibilizo esses dados sob CC0-1.0. Não representam empresas reais e não contêm dados pessoais.

Mantive em `orders.json` cinco pedidos fictícios em snapshot fixo de 17/11/2026 às 12:00 UTC. Valores em centavos de BRL, sem dados pessoais. Estados não evoluem automaticamente; editar a fixture exige manter totais, IDs e timestamps válidos. O hash retornado identifica os bytes consultados, não autentica a fonte.
