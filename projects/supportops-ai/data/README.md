# Dados

Políticas sintéticas criadas para esta demonstração, disponibilizadas sob CC0-1.0. Não representam empresas reais. Não há dados pessoais.

`orders.json` contém cinco pedidos fictícios em snapshot fixo de 17/11/2026 às 12:00 UTC. Valores em centavos de BRL, sem dados pessoais. Estados não evoluem automaticamente; editar a fixture exige manter totais, IDs e timestamps válidos. O hash retornado identifica os bytes consultados, não autentica a fonte.
